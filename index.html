Productos de ejemplo

Estos productos son ficticios y sirven para practicar listado, filtros y futuras integraciones de carrito o checkout.

Cómo seguir construyendo esta tienda

La idea es que uses este proyecto como base y vayas añadiendo funcionalidades paso a paso. Algunas ideas inmediatas:

1. Extiende el catálogo

Añade nuevos productos en el archivo JavaScript, introduce imágenes, descripciones más completas y etiquetas adicionales.

2. Implementa un carrito simple

Empieza guardando los productos seleccionados en memoria o en localStorage y muestra un pequeño resumen en el encabezado.

3. Mejora el diseño

Juega con la tipografía, colores y espaciados. Asegúrate de que la experiencia en móvil sea tan buena como en escritorio.

4. Publica tu proyecto

Crea un repositorio en GitHub, sube el código y actívalo en GitHub Pages para compartir tu tienda con otras personas.

Sobre este repositorio

El objetivo es que sea un ejemplo claro, sin frameworks ni herramientas de build, ideal para entender bien la base del front.

Más adelante puedes migrar este mismo diseño a React, Vue, Svelte o el framework que prefieras, manteniendo la misma estructura conceptual.

  • Estructura minimalista: HTML, CSS, JavaScript plano
  • Sin dependencias externas obligatorias
  • Pensado para ser fácil de leer en GitHub
  • Licencia abierta para usarlo en tus proyectos
